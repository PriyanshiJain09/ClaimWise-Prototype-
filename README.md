# ClaimWise – AI Insurance Navigator

ClaimWise is an AI-powered insurance assistant that helps users understand their policy coverage and navigate the insurance claim process with personalized, source-backed guidance.

### Key Features
- **Policy Analysis:** Understand coverage, benefits, exclusions, and eligibility.
- **Hospital Finder:** Find relevant hospitals based on location and insurance details.
- **AI Web Investigation:** Research official insurer websites for claim procedures and requirements.
- **Smart Claim Preparation:** Get document checklists, deadlines, step-by-step guidance, and claim drafts.
- **Claim Tracking:** Monitor claim progress and pending actions.

### Tech Stack - Prototype 
React · TypeScript · Vite · Tailwind CSS

### Getting Started
```bash
pnpm install
pnpm dev
```
